### Symbol3DUnion
> 用於 3D 場景的圖標類別

![Symbol3DUnion](.storybook\Symbol3DUnion.png)

<p className="sb-unstyled font-bold text-yellow-500">PolygonSymbol3D</p>
`GetPolygonSymbol3D(p_type, p_size, p_color)`

```javascript
let def3DPolygon = {
    type: 'polygon-3d',
    symbolLayers: [{     
        type: p_type,
        size: p_size,
        material: { color: p_color }
    }]
};
```

<p className="sb-unstyled font-bold text-yellow-500">LabelSymbol3D</p>
`GetLabelSymbol3D(p_symtype, p_text, p_size, p_matcolor, p_hacolor, p_hasize, p_family, p_weight, p_fontsty, p_scrlen, p_maxwdlen, p_minwdlen, p_couttype, p_coutsize, p_coutcolor, p_coutbdcolor)`

```javascript
let def3DLabel = {
    type: p_symtype,   
    symbolLayers: [{
        type: 'text',
        text: p_text,
        size: p_size,
        material: { color: p_matcolor },          
        halo: {
            color: p_hacolor, 
            size: p_hasize
        },
        font: {
            family: p_family,
            weight: p_weight,  
            style: p_fontsty    
        }
    }],
    verticalOffset: {
        screenLength: p_scrlen,
        maxWorldLength: p_maxwdlen,
        minWorldLength: p_minwdlen
    },
    callout: new LineCallout3D({
        type:p_couttype,
        size: p_coutsize,
        color: p_coutcolor,
        border: { color: p_coutbdcolor }
    })
};
```
